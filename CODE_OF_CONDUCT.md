# Community Code of Conduct

Daneel's RiTron welcomes respectful participation from people with different
backgrounds and levels of experience. Everyone taking part in project spaces
is expected to help keep them constructive and welcoming.

## Expected behavior

- Be considerate, respectful, and open to constructive discussion.
- Critique ideas and code rather than attacking people.
- Give and accept feedback in good faith.
- Respect differing opinions and experiences.
- Focus on what is best for the project and its community.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwelcome attention.
- Publishing another person's private information without permission.
- Deliberate intimidation, disruption, or sustained bad-faith conduct.
- Any other behavior that a reasonable person would consider inappropriate
  in a collaborative technical community.

## Scope and enforcement

This code applies in project repositories, issues, pull requests, discussions,
and other spaces where someone is representing the project.

Project maintainers may remove content, close discussions, or restrict
participation when behavior violates this code. To report a concern, contact
the project maintainers privately through GitHub. Include relevant links and
context; avoid sharing private information publicly. Maintainers will handle
reports as discreetly as practical. A specific response or resolution timeline
is not guaranteed.
